Politique de confidentialité

Comment Localia protège vos données

Principe fondamental

Localia fonctionne entièrement en local. Aucune donnée n'est envoyée vers des serveurs externes. Votre vie privée est notre priorité.

Données collectées

Aucune donnée personnelle n'est collectée par l'application.

Les données stockées par Localia (profils utilisateurs, playlists, historique d'écoute) le sont exclusivement:

  • Sur votre propre ordinateur/serveur
  • Dans une base de données locale (SQLite)
  • Dans votre navigateur (localStorage)

Utilisation des données

Les données locales sont utilisées uniquement pour:

  • Gérer les profils utilisateurs
  • Stocker vos playlists
  • Se souvenir de la dernière piste lue
  • Compter les lectures pour les recommandations

Ces données ne quittent jamais votre appareil.

Cookies

Localia n'utilise pas de cookies de tracking. Seuls des cookies techniques essentiels au fonctionnement (stockage du token d'authentification) peuvent être utilisés, et ils restent sur votre navigateur.

Accès aux données

Vous êtes le seul maître de vos données.

  • Vous pouvez supprimer toutes les données à tout moment
  • Il suffit de supprimer le fichier de base de données
  • Vous pouvez exporter ou migrer vos données

Sécurité

Nous recommandons de:

  • Activer les codes PIN pour chaque profil
  • Ne pas exposer le serveur sur internet sans VPN
  • Mettre à jour l'application régulièrement
  • Utiliser un pare-feu sur votre réseau local

Contact

Pour toute question concernant cette politique de confidentialité, veuillez ouvrir une issue sur le dépôt GitHub du projet.

Mise à jour
