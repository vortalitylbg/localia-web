Guide d'utilisation

Apprenez à utiliser toutes les fonctionnalités de Localia

Créer un profil

  1. 1. Cliquez sur "Create Account" sur l'écran de connexion
  2. 2. Entrez un nom d'utilisateur (2-20 caractères)
  3. 3. Optionnel: Ajoutez un code PIN à 4 chiffres
  4. 4. Cliquez sur "Create" - vous êtes connecté!

Ajouter de la musique

  1. 1. Cliquez sur l'icône upload dans la barre latérale (à côté du logo)
  2. 2. Glissez-déposez vos fichiers ou cliquez pour parcourir
  3. 3. Formats: MP3, FLAC, WAV, OGG, M4A
  4. 4. Les métadonnées sont récupérées automatiquement

Créer une playlist

  1. 1. Cliquez sur le bouton + à côté de "Playlists" dans le menu latéral
  2. 2. Donnez un nom à votre playlist
  3. 3. Appuyez sur Entrée ou cliquez en dehors
  4. 4. Pour ajouter des titres: utilisez le menu (•••) → Add to playlist

Gamepad (Bêta)

  1. 1. Connectez votre manette (Xbox, PlayStation, etc.)
  2. 2. Appuyez sur une touche pour activer le mode gamepad
  3. 3. Utilisez le stick pour naviguer
  4. 4. A/X = valider, B/O = revenir

⚠️ Fonctionnalité en développement. Des bugs peuvent survenir.

Contrôles clavier

  1. Espace Lecture/Pause
  2. Flèches Volume et seek (±5s)
  3. N Piste suivante
  4. P Piste précédente
  5. G Mode console Gamepad

Utiliser l'égaliseur

  1. 1. Cliquez sur votre profil en bas à gauche
  2. 2. Sélectionnez "Paramètres"
  3. 3. Choisissez un preset ou réglez manuellement
  4. 4. Présélections: Flat, Bass, Rock, Electronic...
