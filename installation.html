Installation

Transformez votre ordinateur en serveur de musique en quelques étapes simples

1

Installer Node.js

Téléchargez et installez Node.js (version 18 ou supérieure).

node --version

🔗 Téléchargez sur: nodejs.org

Windows: lancez l'installateur .msi
macOS: utilisez le package .pkg ou brew install node
Linux: curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash - && sudo apt-get install -y nodejs

2

Récupérer le code

Clonez ou téléchargez le code source.

git clone https://github.com/vortalitylbg/localia.git
3

Installer les dépendances

Installez les paquets nécessaires.

cd localia && npm install
4

Lancer Localia

Démarrez le serveur de développement.

npm run dev
5

Ajouter votre musique

Placez vos fichiers dans le dossier /music ou utilisez l'upload via l'interface.

/music/artist - title.flac

Accéder à Localia

Depuis le serveur

http://localhost:5173

Depuis un autre appareil

http://192.168.1.x:5173

API Backend

http://192.168.1.x:5000

Remplacez 192.168.1.x par l'adresse IP de votre serveur

Conseils

Connexion réseau

Connectez votre serveur en Ethernet pour une meilleure stabilité et vitesse de streaming.

Sécurité

Activez les codes PIN pour chaque profil utilisateur dans les paramètres.

Organisation

Nommez vos fichiers ainsi: "Artiste - Titre.mp3" pour de meilleures métadonnées.
