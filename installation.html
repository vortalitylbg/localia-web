Installation

Transformez votre ordinateur en serveur de musique en quelques étapes simples

1

Téléchargez le script d'installation

Choisissez votre système d'exploitation:

Windows Télécharger .bat Linux / Raspberry Pi Télécharger .sh

💡 Pour Linux/Raspberry: curl -O https://github.com/vortalitylbg/localia/releases/download/v1.0.0/install-linux.sh && chmod +x install-linux.sh && sudo ./install-linux.sh

2

Lancez l'installation

Double-cliquez sur le fichier téléchargé et suivez les instructions à l'écran.

# Windows: double-cliquez sur install-windows.bat # Linux/Raspberry: sudo ./install-linux.sh

⚙️ L'installation automatique installera Node.js, Git et configurera le service.

3

Ajoutez votre musique

Placez vos fichiers dans le dossier music/ ou utilisez l'upload via l'interface.

music/Artiste - Titre.flac

Accéder à Localia

Depuis le serveur

http://localhost:5000

Depuis un autre appareil

http://192.168.1.x:5000

Remplacez 192.168.1.x par l'adresse IP de votre serveur

Commandes avancées

Pour une utilisation avancée sur Linux/Raspberry Pi

Mise à jour

curl -O https://github.com/vortalitylbg/localia/releases/download/v1.0.0/update-linux.sh && chmod +x update-linux.sh && sudo ./update-linux.sh

Désinstallation

curl -O https://github.com/vortalitylbg/localia/releases/download/v1.0.0/uninstall-linux.sh && chmod +x uninstall-linux.sh && sudo ./uninstall-linux.sh

Gestion du service

# Status: sudo systemctl status localia # Redémarrer: sudo systemctl restart localia # Logs: sudo journalctl -u localia -f
